# Prontuário Pré-Anestésico – SASB

Página de acesso ao sistema de avaliação pré-anestésica da SASB – Serviço de Anestesiologia Sul Bahia Ltda.

Este repositório contém apenas a interface (HTML). Logins, senhas, permissões e dados de pacientes ficam no servidor protegido (Supabase, região São Paulo), com controle de acesso por função e registro de auditoria. Nenhum dado de paciente é guardado aqui.
